> **AI-powered food delivery management system built with Python, Tkinter, and SQLite.**

FoodGenie.AI is a modern desktop-based food delivery system that combines food ordering, restaurant management, delivery tracking, and AI-powered personalization into a single application.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/FoodGenie.AI.git
```

### 2. Open the Project

```bash
cd FoodGenie.AI
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python main.py
```

---

## 🪟 Windows EXE

FoodGenie.AI can also be packaged as a standalone Windows application using PyInstaller.

```bash
python -m PyInstaller --onefile --windowed --name FoodGenieAI main.py
```

The executable will be generated inside:

```text
dist/FoodGenieAI.exe
```

## 🎯 Project Objective

The objective of FoodGenie.AI is to develop a complete food delivery management system that combines traditional ordering functionality with AI-assisted food discovery and personalization.

The system demonstrates how customers, restaurants, delivery partners, and administrators can interact through a unified desktop application.
